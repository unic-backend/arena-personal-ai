1. RÉSUMÉ EXÉCUTIF & VISION
--------------------------------------------------------------------------------
Usman est un système d'IA autonome local-first de niveau mondial ("Frontier AI"),
conçu au Sénégal par Usman. Le système fonctionne à 100% sur la machine locale de 
Usman (NVIDIA RTX A2000 12GB VRAM, 32GB RAM, Windows 11) sans dépendre d'API cloud
payantes externes.

Le projet est conçu pour évoluer de manière transparente d'une IA personnelle 
privée vers une plateforme publique mondiale (SaaS) multi-utilisateurs.

3. ÉQUIPE COMPLÈTE DE 12 AGENTS D'ÉLITE (AGENTS ACTIVE)
--------------------------------------------------------------------------------
1. OrchestratorAgent     : Routage ultra-rapide (0.001s) selon l'intention.
2. CoderAgent            : Programmation Python autonome avec auto-correction 
                           en Bac à Sable OpenSandbox.
3. RepoEngineerAgent     : Ingénierie logicielle multi-fichiers (Odysseus/Devin Pattern).
4. SWEAgent              : Résolution chirurgicale de bugs ligne par ligne 
                           (Princeton NLP ACI Pattern).
5. DeepResearcherAgent   : Rapports d'intelligence stratégiques multi-sources 
                           (Kimi / Perplexity Pattern).
6. ReasoningEngine       : Démonstrations mathématiques et scientifiques avec 
                           calculs exacts SymPy / NumPy (Plan & Solve Pattern).
7. TrendAnalyzerAgent    : Analyse des tendances web en direct (Sénégal, Afrique, Monde).
8. VideoAnalyzerAgent    : Transcription audio Whisper & compréhension vidéo.
9. ClipSelectorAgent     : Détection du meilleur extrait viral (Hook) et découpe.
10. EditorAgent          : Reformatage vertical 9:16 (1080x1920) avec flou.
11. SubtitleAgent        : Génération de sous-titres synchronisés (.srt).
12. PublisherAgent       : Simulation de publication sociale avec hashtags/titres.

8. RAPPEL DES COMMANDES DE DÉMARRAGE
--------------------------------------------------------------------------------
Pour lancer la plateforme Usman :

1. Lancer Docker Desktop sur Windows.
2. Dans VS Code (C:\Users\Usman\personal_ai), ouvrir un terminal et exécuter :
   python -m uvicorn apps.backend.main:app --host 127.0.0.1 --port 8000
3. Dans un deuxième terminal :
   docker compose up -d
4. Accéder aux interfaces :
   - LibreChat : http://localhost:3080
   - Open WebUI : http://localhost:3000
   - Studio Vidéo : http://127.0.0.1:8000
